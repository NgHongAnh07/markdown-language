# Sherlock Holmes - The Famous Detective

Sherlock Holmes is a fictional detective created by Sir Arthur Conan Doyle. He lives in London and is famous for solving difficult mysteries using observation and logical thinking.

## Why I Like Sherlock Holmes

**Sherlock Holmes is one of my favorite fictional detectives because he is very intelligent.**

*I enjoy the way he notices small details that other people miss.*

***His logical thinking and problem-solving skills make his stories exciting to read.***

### Main Characters

- Sherlock Holmes - A clever detective who solves mysteries.
- Dr. John Watson - Holmes's best friend and assistant.
- Professor Moriarty - A dangerous criminal and enemy of Holmes.
- Mrs. Hudson - The landlady where Holmes lives.

## How Sherlock Holmes Solves Mysteries

1. Visit the crime scene.
2. Observe the surroundings carefully.
3. Collect important clues.
4. Interview witnesses and suspects.
5. Think logically about the evidence.
6. Find the truth and solve the mystery.

### Detective Skills

Sherlock Holmes uses several skills to investigate cases.

- Observation
- Logical reasoning
- Problem-solving
- Attention to detail
- Scientific knowledge

## A Simple Detective Code Example

If Sherlock Holmes used Python, he could create a list of clues and check them one by one.

In Python, the command `print()` displays information on the screen.

```python
clues = ["Footprints", "Broken window", "Lost key"]

for clue in clues:
    print("Investigating:", clue)
```

This program displays each clue. It is a simple example of how a detective can organize information during an investigation.
